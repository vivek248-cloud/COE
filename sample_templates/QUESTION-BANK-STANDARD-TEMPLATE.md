# HCC Standard Question Bank Template

## Course header

Write the **course code once in the header only**. Do not repeat it in question rows.

Example:

`COURSE CODE,U25TL3GEN03`

## Question columns

| Column | Required | Rule |
|---|---|---|
| Q.No | Yes | Sequential: 1, 2, 3, ... |
| Unit | Yes | 1–5 |
| Sub-Unit | Yes | 1.1, 1.2, 2.1, etc. |
| Section | Yes | SECTION-A, SECTION-B, SECTION-C, SECTION-D |
| Marks | Yes | Approved marks for that question |
| K-Level | Yes | K1–K6 |
| CO | Yes | CO1–CO6, according to the approved course mapping |
| Question Type | Yes | MCQ, MATCH, ASSERTION_REASON, VSA, PARAGRAPH, ESSAY |
| Question | Yes | Complete question text |
| Option A-D | MCQ | Enter four options separately |
| Answer Key | MCQ/where applicable | A/B/C/D or the official answer |
| Image URL | Optional | Image/diagram path or URL |
| Formula LaTeX | Optional | Mathematical formula |
| Assertion / Reason | Optional | Use for Assertion-Reason questions |
| Match columns | Optional | Use for Match questions |
